# Lenker Composite v3 — CA

Static website mockup for peer review.

Live preview: https://cesar-acosta551.github.io/lenker-composite-v3-ca/

The mockup uses `index.html`, local image assets in `a/` and `p/`, and fonts in `fonts/`. No build step is needed.

To preview locally, run `python3 -m http.server 8000` from this folder, then open http://localhost:8000/.

GitHub Pages publishes the root of the `main` branch. To publish updates:

```sh
git add index.html a/ p/ fonts/
git commit -m "Update v3 mockup"
git push
```

The Full / Focus / Sprint length controls and Photo / Gauge hero controls are included for review. This is a design mockup; placeholder content and interactions may be present. The contact form is a mockup and does not deliver submissions.
